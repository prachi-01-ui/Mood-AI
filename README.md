# Mood AI 🎭

An AI-powered system that detects human emotions in real-time using computer vision and responds with voice, music, and gesture-based interaction.

## 🚀 Features
- Real-time emotion detection using DeepFace
- Voice assistant using gTTS + pygame
- Gesture control using MediaPipe
- Music recommendation based on mood
- Interactive UI with OpenCV

## 🧠 Tech Stack
- Python
- OpenCV
- DeepFace
- MediaPipe
- gTTS
- NumPy
